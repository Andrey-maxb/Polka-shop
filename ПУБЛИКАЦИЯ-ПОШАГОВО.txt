===========================================================
  ПУБЛИКАЦИЯ МАГАЗИНА В ИНТЕРНЕТЕ — ПОШАГОВО
  GitHub + Render. Всё бесплатно, ~15 минут.
===========================================================

ЧТО ПОЛУЧИТСЯ
  Ссылка вида  https://polka-shop.onrender.com
  Открывается с любого устройства, можно отправлять людям.
  Домен (polka.ru) покупать НЕ обязательно — привяжете позже.


-----------------------------------------------------------
ШАГ 0. РАСПАКОВАТЬ АРХИВ
-----------------------------------------------------------
Распакуйте polka-ready.zip в папку без русских букв в пути,
например:  C:\polka
Внутри должна лежать папка polka-pack — её содержимое и заливаем.


-----------------------------------------------------------
ШАГ 1. GITHUB — хранилище вашего кода (бесплатно)
-----------------------------------------------------------
1. Откройте  https://github.com  → Sign up (если аккаунта нет).
   Нужны почта, пароль, имя пользователя.

2. Войдите → в правом верхнем углу «+» → New repository.

3. Заполните:
   Repository name:  polka-shop
   Видимость:        Public  (для бесплатного Render проще всего)
   галочку «Add a README file» НЕ ставить
   → Create repository

4. На открывшейся странице будет строка
   «…or upload an existing file» → нажмите эту ссылку.

5. Откройте папку polka-pack в проводнике Windows,
   выделите ВСЁ содержимое (Ctrl+A) и перетащите мышкой
   в окно браузера на страницу GitHub.

   ВАЖНО: перетаскивать нужно содержимое папки
   (app.py, config.py, static, data и т.д.), а не саму папку polka-pack.
   Если случайно перетащили папку — не страшно, потом поправим.

6. Внизу нажмите зелёную кнопку  «Commit changes».

7. Проверка: на странице репозитория должны быть видны
   папки static, data, integrations и файлы app.py, config.py,
   requirements.txt, render.yaml.


-----------------------------------------------------------
ШАГ 2. RENDER — хостинг, где сайт будет работать (бесплатно)
-----------------------------------------------------------
1. Откройте  https://render.com  → Get Started
   → проще всего войти через «Sign in with GitHub» (одна кнопка).

2. Разрешите Render доступ к вашим репозиториям
   (Install & Authorize, можно выбрать только polka-shop).

3. В панели Render:  New +  →  Web Service

4. Выберите репозиторий  polka-shop  → Connect.

5. Заполните поля:
   Name:             polka-shop
   Region:           Frankfurt (ближе к России)
   Branch:           main
   Runtime/Language: Python 3
   Build Command:    оставить ПУСТЫМ  (можно вписать: pip install -r requirements.txt)
   Start Command:    python3 app.py
   Instance Type:    Free

6. Ниже → «Advanced» / «Environment Variables» → Add Environment Variable.
   Добавьте две:

      ADMIN_PASSWORD   =  придумайте свой пароль (например Polka2026!)
      SHOP_URL         =  https://polka-shop.onrender.com

   (SHOP_URL можно потом уточнить, когда узнаете точный адрес.)

7. Нажмите  «Create Web Service»  и подождите 2–4 минуты.
   В окне логов появится:
      ПОЛКА: http://0.0.0.0:10000 | админка /admin | оплата: demo
      ==> Your service is live 🎉

8. Сверху будет ссылка вида
      https://polka-shop.onrender.com
   Откройте её — это ваш магазин в интернете.
   Админка:  https://polka-shop.onrender.com/admin   (пароль из шага 6)


-----------------------------------------------------------
ШАГ 3. ПРОВЕРКА
-----------------------------------------------------------
Проверьте по списку:
  [ ] Главная открывается, товары видны
  [ ] Каталог, фильтры, поиск работают
  [ ] Товар → «Добавить в корзину»
  [ ] Оформление: выбрать город и ПВЗ → появилась стоимость доставки
  [ ] «Оплатить заказ» → заказ создан (демо-платёж)
  [ ] /admin → вход по вашему паролю → «Товары и остатки»,
      поменять остаток и сохранить
  [ ] Открыть ссылку с телефона — вёрстка не разъезжается


-----------------------------------------------------------
ВАЖНО ПРО БЕСПЛАТНЫЙ ТАРИФ RENDER
-----------------------------------------------------------
1. Сон после 15 минут без посетителей.
   Первый заход после простоя — «холодный старт» 30–60 секунд.
   Потом работает быстро. Это нормально для теста и показа.

2. Данные (заказы, остатки) СБРАСЫВАЮТСЯ при перезапуске сервиса,
   потому что на free-тарифе нет постоянного диска.
   Для реальных продаж нужно:
     - перейти на платный инстанс (Starter ~$7/мес) и подключить Disk,
       примонтированный в папку  /opt/render/project/src/data
       (тогда файл базы сохраняется), ИЛИ
     - перейти на внешнюю базу PostgreSQL.

3. Пароль админки хранится в переменных Render, а не в коде — это правильно.
   Файл .env в репозиторий не заливайте (он в .gitignore).


-----------------------------------------------------------
ШАГ 4. СВОЙ ДОМЕН (когда захотите, ~500 ₽/год)
-----------------------------------------------------------
1. Купите домен на reg.ru или timeweb.ru
   (например  polka-shop.ru). Не берите хостинг у них — он не нужен.

2. В Render: ваш сервис → Settings → Custom Domains → Add
   → впишите домен  polka-shop.ru

3. Render покажет DNS-записи, например:
      A     @      216.24.57.1
      CNAME www    polka-shop.onrender.com
   Ровно эти записи добавьте в панели регистратора домена
   в разделе «DNS-серверы / Управление зоной».

4. Подождите 10 минут – 2 часа. Render сам выпустит
   бесплатный HTTPS-сертификат (замочек в браузере).

5. В переменной SHOP_URL на Render замените адрес на новый домен
   и нажмите «Save» (сервис перезапустится).

        https://ваш-домен.ru/api/payments/webhook
  [ ] Ozon Seller API: OZON_MODE=api + OZON_CLIENT_ID / OZON_API_KEY
  [ ] Платный инстанс + постоянный диск (иначе заказы пропадут)


-----------------------------------------------------------
ЧТО ДЕЛАТЬ, ЕСЛИ ЧТО-ТО НЕ ТАК
-----------------------------------------------------------
Render показывает логи в реальном времени — там видно причину.

«Application failed to respond»     → Start Command должен быть  python3 app.py
«No such file app.py»               → при заливке на GitHub папка оказалась
                                      вложенной: файлы должны лежать в корне
                                      репозитория, а не в polka-pack/
Порт уже занят / сервер не стартует → ничего не меняйте, app.py сам берёт
                                      PORT из окружения Render
Магазин «спит»                       → это free-тариф, зайдите ещё раз и
                                      подождите 40 секунд
Не пускает в /admin                  → пароль задан в ADMIN_PASSWORD на Render;
                                      после изменения переменной сервис
                                      перезапускается автоматически
