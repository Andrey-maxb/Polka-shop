Вариант 0. САМОЕ БЫСТРОЕ — один файл, без установки
-----------------------------------------------------------
Откройте файл  static/demo.html  (или ПОЛКА-демо.html из архива)
двойным кликом в любом браузере. Внутри уже всё: каталог, корзина,
оформление, ПВЗ и админка (static/admin-demo.html).

  Это автономная демо-версия: сервер не нужен, данные не отправляются
  никуда, заказы и правки остатков живут в памяти страницы.

  ВАЖНО: адрес  localhost:8000  работает ТОЛЬКО если вы запустили
  python3 app.py у себя на компьютере. Ссылка из чата (LIVE PREVIEW)
  и файл demo.html открываются без локального сервера.


Вариант 1. ЖИВОЙ САЙТ С СЕРВЕРОМ (в чате)
-----------------------------------------------------------
В чате нажмите на превью (LIVE PREVIEW, порт 8000) — там настоящий
сайт с базой: витрина, каталог, корзина, оформление с выбором ПВЗ,
админка по адресу  /admin  (пароль: polka2026)

Что посмотреть за 2 минуты:
  1. Каталог → любой товар → «Добавить в корзину»
  2. Корзина → «Оформить заказ»
  3. Заполнить имя/телефон → выбрать город и ПВЗ Ozon
     → в этот момент появляется стоимость доставки и итог
  4. «Оплатить заказ» → на странице заказа нажать «Оплатить»
     (демо-платёж) → статус меняется на «Оплачен»
  5. Зайти в /admin → пароль polka2026:
       «Сводка»          — выручка по дням
       «Товары и остатки»— правите цену и остаток, кнопка «Сохранить»
                           или «Остаток всем» (поставить 100 шт. везде)
       «Заказы»          — состав, ПВЗ, смена статуса, отмена
                           (отмена возвращает товар на склад)


Вариант 2. ЗАПУСТИТЬ У СЕБЯ НА КОМПЬЮТЕРЕ
-----------------------------------------------------------
Нужен только Python 3 — больше ничего ставить не надо,
зависимостей у проекта нет.

  Windows:      двойной клик по  start-windows.bat
  Mac / Linux:  bash start-mac-linux.sh

Или вручную:
  python3 app.py        (Windows: python app.py)

Затем откройте  http://localhost:8000
Админка:        http://localhost:8000/admin   пароль: polka2026
Пароль меняется в файле .env → ADMIN_PASSWORD


Вариант 3. ВЫЛОЖИТЬ В ИНТЕРНЕТ (бесплатно)
-----------------------------------------------------------
Самый простой путь — Render.com:
  1. Загрузите папку в репозиторий на GitHub
  2. Render → New → Web Service → выбрать репозиторий
  3. Build Command: пусто
     Start Command: python3 app.py
  4. В Environment добавить ADMIN_PASSWORD и SHOP_URL
  5. Получите ссылку вида https://polka-shop.onrender.com

Подробно (включая VPS и Docker) — в файле README.md


ЧТО НАСТРОИТЬ ПЕРЕД ПРОДАЖАМИ
-----------------------------------------------------------
Файл .env:
  ADMIN_PASSWORD   — сменить обязательно (сейчас polka2026)
  SELLER_NAME, SELLER_INN, SELLER_EMAIL — ваши реквизиты для чека
  SHOP_URL         — адрес сайта после публикации
  PAYMENT_PROVIDER — yookassa / cloudpayments / robokassa
                     (пока demo: заказ создаётся без реальных денег)
  YOOKASSA_SHOP_ID, YOOKASSA_SECRET_KEY — ключи из личного кабинета
  VAT_CODE, SNO   — НДС и система налогообложения
  OZON_MODE=api + OZON_CLIENT_ID/OZON_API_KEY — реальный Ozon
  DELIVERY_BASE, DELIVERY_PER_KG, DELIVERY_FREE_FROM — тариф доставки

Полная инструкция по каждому пункту — README.md,
разделы «Подключение Ozon» и «Подключение оплаты и кассы».
